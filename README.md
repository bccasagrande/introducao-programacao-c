# Introdução à Programação de Computadores – Linguagem C

Este repositório contém os trabalhos desenvolvidos para a disciplina
Introdução à Programação de Computadores, utilizando a linguagem C.

## Conteúdos abordados
- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores
- Estruturas de decisão
- Estruturas de repetição
- Vetores e matrizes
